# 🏫 와우고 수능 시험장 3D 안내도 (2027학년도)

2027학년도 대학수학능력시험 와우고등학교 시험장의 **시험실·대기실을 3D 로 돌려 보며 찾는** 안내도입니다.
「와우고 3D 교실 안내도」(wawoohs-3d)를 바탕으로, 시험장으로 쓰는 방만 이름과 색을 표시하도록 바꾸었습니다.

👉 **바로 열기: https://trmoo.github.io/csat2027/**

## 표시하는 방 (33곳)

| 층 | 방 |
|---|---|
| 4층 | 시험실 1~12 |
| 3층 | 시험실 13~22 · 예비시험실 1·2 · 감독관 대기실 2(정보융합실) |
| 2층 | 수험생 휴게실 · 수험생 대기실 · 시험관리본부 · 감독관 대기실 1(도서관) |
| 1층 | 감독관 연수장소(시청각실) · 식당 · 교육행정실 · 보건실 |

- 그 밖의 방은 **회색으로 낮게만** 그리고 이름·용도를 보이지 않습니다(누를 수도, 검색할 수도 없습니다).
- 계단·화장실은 표시하지 않습니다. 승강기만 남겨 두었습니다.

## 쓰는 법

- **시험실 찾기** — 「시험실 7」, 「7」, 「예비」, 「대기실」 처럼 넣고 Enter. 그 방이 빨갛게 표시되고 카드에 층과 건물(전관·후관 …)이 나옵니다.
- **층 선택** — 전체 / 1~4층. 층을 고르면 그 층만 보입니다.
- **확대** — 휠·두 손가락으로 가까이 가면 시험실 번호 글씨가 커집니다(최대 3배).
- **색상 안내** — 색을 누르면 그 종류만 강조되고 방 목록이 층별로 펼쳐집니다.
- **링크** — 카드의 [이 방 링크 복사]. `#f3` 은 3층, `#all` 은 전체입니다.

## 나눠 주기

- 주소 https://trmoo.github.io/csat2027/ 를 알려 주거나, `npm run build` 로 만든 `dist/index.html` 한 파일을 나눠 주면 됩니다. 인터넷 없이 더블클릭으로 열립니다.
- 앱 폴더의 `index.html` 은 개발용이라 그냥 열면 빈 화면입니다.

## 만드는 사람을 위한 명령

| 명령 | 하는 일 |
|---|---|
| `npm install` | 의존성 설치 |
| `npm start` | 개발 서버 |
| `npm run build` | `dist/index.html` 한 파일로 빌드 + 점검(원래 교실 이름이 새지 않았는가 포함) |
| `npm test` | 자료 점검(시험실 22개·층·차례·이름 없는 방·검색) |
| `npm run data` | `source/school_base.json`(교실 안내도 자료 — 저장소에는 올리지 않음) → 시험장 자료로 다시 만든다 |

배치가 바뀌면 `tools/make_exam.mjs` 의 `MAP`(원래 방 → 시험장 용도)을 고치고 `npm run data` → `npm test` → `npm run build`.
